# Islamic Finance Hub — Zakat & Sadaqah Calculators

Sharia-compliant financial calculators for Zakat, Sadaqah, and Islamic wealth management.

## Features

- 💰 **Zakat Calculator** — Calculate obligatory charity with asset/liability breakdown
- 🤲 **Sadaqah Estimator** — Get personalized voluntary charity suggestions
- 📊 **Sadaqah Tracker** — Track donations over time with localStorage
- 💱 **Multi-Currency** — USD, GHS, NGN, GBP, EUR, SAR, AED support
- 📖 **Knowledge Base** — What is Zakat, Riba, Nisab, Islamic Banking explained
- 📋 **Quick Reference** — Zakat rates for different asset types
- 📱 **PWA Support** — Works offline after first visit

## Zakat Calculation

- Inputs: Cash, Gold/Silver, Stocks, Business, Property, Pension
- Deductions: Debts, Immediate Expenses
- Nisab threshold: ~85g gold value (varies by currency)
- Rate: 2.5% of net zakatable wealth

## Quick Start

```bash
cd Islamic_Finance
python3 -m http.server 8080
# Open http://localhost:8080
```

## Tech

Single-file HTML/CSS/JS application. No build step, no dependencies.
